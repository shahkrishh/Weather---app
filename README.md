# Weather App

A simple Java weather app that shows current conditions and a 7-day forecast for any city.

## Features
- Search any city
- Current temperature, humidity, and wind
- 7-day forecast

## Requirements
- Java 17 or newer
- A free weather API key (e.g., OpenWeatherMap)

## Setup
1. Clone the repo: `git clone https://github.com/shahkrishh/Weather---app.git`
2. Add your API key in the config file
3. Build and run the project
